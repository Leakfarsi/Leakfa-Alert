Leakfa Alert Browser Extension automatically checks the domain of every website you visit against Leakfa's database of known data breaches.

If the current website has a known history of data exposure, the extension immediately notifies you while you browse.

The extension is fully open source and designed with privacy as its highest priority.

---

## 📌 About

The goal of this extension is to improve users' awareness of the security history of the websites they visit.

Instead of manually searching every domain, the extension performs the check automatically in the background and alerts users whenever necessary.

---

## 🚀 Features

- 🛡️ Automatic detection of breached websites
- ⚡ Real-time monitoring while browsing
- 🔒 Privacy-first design
- 💻 Fully open source
- 🌐 Persian and English support
- 🎯 Powered by Leakfa breach database

---

## 🔒 Privacy

Privacy is the core principle of this project.

- ✅ No browsing data is transmitted to any server.
- ✅ All checks are performed locally inside your browser.
- ✅ Only the current website domain is compared against the local database.

## 🧩 Installation

Install the extension for Google Chrome directly from the Chrome Web Store.

```
‍‍‍https://chromewebstore.google.com/detail/mlfokglbmlcembbcamgniolbcghonbaj
```

```

```

